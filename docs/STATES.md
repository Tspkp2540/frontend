# Frontend states

| Flow | การแสดงผลและทางไปต่อ |
|---|---|
| ตรวจ session | รอผล; ไม่ได้ login กลับหน้า login แล้วคืนหน้าที่ขอรวมตัวกรอง |
| Session lookup ล้มเหลว | แสดง error และลองใหม่ |
| สมัคร / login / logout ล้มเหลว | แจ้งเหตุผล เก็บข้อมูลที่กรอก; 429 แสดงเวลารอ |
| โหลดห้อง | Skeleton; error มีลองใหม่; ไม่มีห้องแสดง empty state |
| ค้นหาไม่พบ | แจ้งไม่พบ ใช้ปุ่มล้างตัวกรองจุดเดียว |
| รูปโหลดไม่ได้ | ภาพแทน ยังเปิดห้องและจองได้ |
| ห้อง / URL ไม่พบ | มีลิงก์กลับหน้าห้องพัก |
| โหลดปฏิทินไม่ได้ | Error/retry และปิดการยืนยัน; เก็บข้อมูลผู้เข้าพัก |
| เดือนเต็ม | แนะนำเปลี่ยนเดือนหรือห้อง |
| วันพัก / ข้อมูลไม่ถูกต้อง | แจ้งข้าง field หรือฟอร์มก่อนส่ง |
| ยืนยันจอง / ยกเลิกกำลังส่ง | ล็อกปุ่มซ้ำและปิด modal ไม่ได้ |
| วันชนระหว่างยืนยัน | เก็บข้อมูลผู้เข้าพัก ล้างวันและอัปเดตปฏิทิน |
| จองสำเร็จ แต่ refresh ปฏิทินล้มเหลว | แสดงใบยืนยัน; แสดง error/retry เมื่อกดกลับปฏิทิน |
| ส่งจองแล้วไม่ทราบผล | Alert เดียวพร้อมตรวจผล/ส่งคำขอเดิมซ้ำ ไม่ส่งอัตโนมัติ |
| Reload หลังคำขอไม่ทราบผล | ตรวจ request key เดิม; พบผลแสดงใบยืนยัน ไม่พบให้ตรวจซ้ำหรือกรอกข้อมูลเดิมส่งด้วย key เดิม |
| ประวัติการจอง | Loading/empty/error; โหลดเพิ่มล้มเหลวคงรายการเดิมและลองหน้าเดิมซ้ำ |
| ยกเลิก | ยืนยันก่อนส่ง; สำเร็จเปลี่ยนสถานะ/คืนวันว่าง; cancelled หรือถึงวันเข้าพักไม่แสดงปุ่ม |
| ยกเลิกแล้วไม่ทราบผล | คง modal พร้อมลองคำขอเดิมซ้ำได้; 4xx แสดงเหตุผลที่ทราบแน่ชัด |
| เปลี่ยนบัญชี / session หมดอายุ | ล้าง private cache; หมดอายุมี modal ไป login |
| Render / lazy page ล้มเหลว | หน้า reload และลิงก์กลับห้องพัก |

ค้นหา q/province จาก URL ใช้ร่วมกันแบบ AND คงค่าเมื่อ reload/back/share หรือกลับจากห้อง จังหวัดไม่มีใน catalogue แสดง no match ไม่ถือเป็นระบบล่ม

API timeout 15 วินาที; server 5xx ใช้ข้อความทั่วไป ไม่แสดง diagnostics ภายใน Backend ยังตรวจเจ้าของ/วันที่/วันว่างเสมอ

Request key เก็บใน sessionStorage แยกตามผู้ใช้/ห้อง ไม่มี guest fields; สำเร็จแล้วลบ ปิดแท็บหรือ storage ถูกปิดอาจกู้หลัง reload ไม่ได้ มี memory fallback ขณะอยู่ในแอป Lookup404 หมายถึงยังไม่เห็นผลที่ commit ไม่ได้ยืนยันว่าคำขอล้มเหลว
